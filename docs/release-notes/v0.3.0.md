Celdas 0.3.0 edita y guarda las macros VBA de tus libros y dibuja formas, imágenes y gráficos como dice el archivo.
*Celdas 0.3.0 edits and saves the VBA macros of your workbooks and draws shapes, pictures and charts as the file says.*

## Español

### Novedades
- Editor VBA: Automatizar › Macros › Editar abre una lista de módulos y un editor de código con colores. Guardar reescribe el `vbaProject.bin` del libro (solo cambian los módulos editados, el resto del archivo queda igual), como un solo paso de deshacer; la siguiente ejecución vuelve a pedir aprobación porque el código cambió. También puedes crear módulos nuevos, eliminarlos y ejecutar un procedimiento desde el editor. Nuevas órdenes `vba.save` y `vba.remove` para scripts, la CLI y MCP.
- Formas y botones: los colores de tema con «más claro» y «más oscuro», los contornos y rellenos que vienen del estilo de la forma, el bisel, los márgenes internos y el formato de cada tramo de texto (cursiva, negrita, color) se dibujan como en el archivo; ya no aparecen bordes que Excel no dibuja.
- Imágenes con recorte (`srcRect`) se muestran y se guardan recortadas.
- Gráficos: las entradas de la leyenda que el archivo oculta (por ejemplo las líneas de tendencia) ya no aparecen, y se conservan al guardar.
- Los números de fila de la cuadrícula se ajustan a su cabecera.

### Notas
- No hay Excel en el equipo de desarrollo para comparar: el dibujo sigue el XML del archivo, pero no se ha medido píxel a píxel contra Excel, y no se ha probado que Excel abra un proyecto VBA reescrito.
- Todavía no hay UserForms ni eventos de hoja o libro, y no se puede crear un proyecto VBA en un libro que no tenga ninguno.

## English

### What's new
- VBA editor: Automate › Macros › Edit opens a module list and a code editor with highlighting. Save rewrites the workbook's `vbaProject.bin` (only the edited modules change, the rest of the file stays as it was) as one undo step; the next run asks for approval again because the code changed. You can also add and delete modules and run a procedure from the editor. New `vba.save` and `vba.remove` commands for scripts, the CLI and MCP.
- Shapes and buttons: theme colours with "lighter" and "darker", outlines and fills that come from the shape's style, bevels, text insets and the format of each text run (italic, bold, colour) are drawn as the file says; outlines Excel doesn't draw no longer appear.
- Pictures with a crop (`srcRect`) show and save cropped.
- Charts: legend entries the file hides (for example trendlines) no longer show, and are kept on save.
- Row numbers in the grid fit their header.

### Notes
- There is no Excel on the development machine to compare with: drawing follows the file's XML but has not been measured pixel by pixel against Excel, and Excel opening a rewritten VBA project has not been tested.
- There are still no UserForms or sheet or workbook events, and a workbook with no VBA project cannot get one from scratch.
