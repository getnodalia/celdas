Celdas 0.5.0 trae un editor de macros Visual Basic nuevo: moderno, con el diseño de Nodalia y con depurador.
*Celdas 0.5.0 brings a new Visual Basic macro editor: modern, in the Nodalia design, with a debugger.*

## Español

### Novedades
- **Editor de Visual Basic (Alt+F11)** a pantalla completa, con el diseño de Nodalia en claro y oscuro: barra de herramientas, explorador del proyecto con esquema de procedimientos, pestañas por módulo y un panel inferior con Problemas, Inmediato, Variables locales, Inspección, Pila de llamadas y Salida.
- **Escribir código con ayuda:** resaltado de VBA, números de línea, errores y advertencias mientras escribes, sugerencias con documentación y la firma de la función que estás escribiendo, información al pasar el ratón, Ir a la definición (F12), Buscar y reemplazar (Ctrl+F, Ctrl+H, F3) y Dar formato al módulo (Ctrl+Shift+F).
- **Depurador:** puntos de interrupción (F9), Paso a paso por instrucciones (F8), por procedimientos (Shift+F8) y Salir del procedimiento (Ctrl+Shift+F8), Continuar (F5) y Detener (Shift+F5). Con la macro en pausa se ven las variables locales, las inspecciones y la pila de llamadas, y la ventana Inmediato ejecuta en el procedimiento en pausa.
- **Ventana Inmediato:** escribe una instrucción, o `?` y una expresión, y se ejecuta en el libro.
- **Libros sin proyecto:** el editor ofrece crear un proyecto de macros con un módulo de ejemplo, o grabar una macro.
- **Diálogo Macros (Alt+F8)** renovado: cada fila muestra su tipo (macro, script o VBA) con un icono, Ejecutar es el botón principal, Paso a paso también abre en el editor las macros VBA, y el botón nuevo «Macro VBA nueva» añade un `Sub` vacío al proyecto.

### Correcciones
- Los errores de una macro VBA indican la línea tal como la cuenta el editor, sin contar las líneas `Attribute` del módulo.

## English

### What's new
- **Visual Basic editor (Alt+F11)** full window, in the Nodalia design in light and dark: a toolbar, a project explorer with an outline of procedures, one tab per module and a bottom panel with Problems, Immediate, Locals, Watch, Call Stack and Output.
- **Writing code with help:** VBA highlighting, line numbers, errors and warnings as you type, suggestions with documentation and the signature of the call you are typing, hover information, Go to Definition (F12), Find and Replace (Ctrl+F, Ctrl+H, F3) and Format Module (Ctrl+Shift+F).
- **Debugger:** breakpoints (F9), Step Into (F8), Step Over (Shift+F8), Step Out (Ctrl+Shift+F8), Continue (F5) and Stop (Shift+F5). While a macro is paused you see its locals, watches and call stack, and the Immediate window runs in the paused procedure.
- **Immediate window:** type a statement, or `?` and an expression, and it runs in the workbook.
- **Workbooks without a project:** the editor offers to create a macro project with a sample module, or to record a macro.
- **Macros dialog (Alt+F8)** redone: each row shows its kind (macro, script or VBA) with an icon, Run is the primary button, Step Into also opens VBA macros in the editor, and the new "New VBA Macro" button adds an empty `Sub` to the project.

### Fixes
- Errors of a VBA macro name the line as the editor counts it, without the module's `Attribute` lines.
