Celdas 0.2.0 ejecuta las macros VBA de tus libros de Excel.
*Celdas 0.2.0 runs the VBA macros of your Excel workbooks.*

## Español

### Novedades
- Los procedimientos VBA de un `.xlsm` se ejecutan en Celdas: Automatizar › Macros los lista junto a las macros de Celdas y los ejecuta, y un clic en una forma con macro asignada la ejecuta, como en Excel. Un libro abierto desde un archivo pregunta antes de ejecutar su primera macro.
- Cada ejecución es un solo paso de deshacer y todo o nada: si la macro falla, el libro y los archivos que iba a escribir quedan como estaban, y el error indica módulo, procedimiento y línea.
- El modelo de objetos de Excel cubre hojas, rangos y celdas (valores, fórmulas, formato, bordes, combinar, autoajuste), formas y gráficos (`AddChart2`, series, títulos), `WorksheetFunction`, `Evaluate`, libros nuevos y archivos de texto (`Open`, `Print #`, `Line Input #`, `Dir`, `MkDir`, `Kill`). Un libro de prácticas de turbomáquinas con tres macros largas reproduce celda a celda los resultados que Excel dejó guardados.
- Nuevas órdenes `vba.list`, `vba.source` y `vba.run` para scripts, la CLI y MCP.

### Notas
- Todavía no hay UserForms, eventos de hoja o libro, ni editor VBA. Un procedimiento que los use falla con un error que lo nombra y no cambia nada.

## English

### What's new
- The VBA procedures of an `.xlsm` run in Celdas: Automate › Macros lists them beside Celdas macros and runs them, and a click on a shape with a macro assigned runs it, as in Excel. A workbook opened from a file asks before its first macro runs.
- Every run is one undo step and all or nothing: when the macro fails, the workbook and the files it would have written stay as they were, and the error names the module, procedure and line.
- The Excel object model covers sheets, ranges and cells (values, formulas, formatting, borders, merge, autofit), shapes and charts (`AddChart2`, series, titles), `WorksheetFunction`, `Evaluate`, new workbooks and text files (`Open`, `Print #`, `Line Input #`, `Dir`, `MkDir`, `Kill`). A turbomachinery coursework workbook with three long macros reproduces, cell for cell, the results Excel saved in it.
- New `vba.list`, `vba.source` and `vba.run` commands for scripts, the CLI and MCP.

### Notes
- There are no UserForms, sheet or workbook events or VBA editor yet. A procedure that uses them fails with an error naming it and changes nothing.
