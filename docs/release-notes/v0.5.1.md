Celdas 0.5.1 deja la ventana Acerca de solo con lo esencial y limpia el código que ya no se usaba.
*Celdas 0.5.1 leaves the About window with only the essentials and removes code that was no longer used.*

## Español

### Correcciones
- **Acerca de**, sin listas de colaboradores ni de modelos: la ventana es la página común de Nodalia (icono, versión, enlaces y el aviso de autoría original), y la descripción de su botón en la cinta ya no habla de colaboradores ni de modelos de IA.
- Se retira del programa el código y los datos de esas listas, que ya no se mostraban.

## English

### Fixes
- **About** has no contributor or model lists: the window is the shared Nodalia page (icon, version, links and the original authorship notice), and its ribbon button no longer mentions contributors or AI models.
- The code and data behind those lists, no longer shown, are removed from the program.
