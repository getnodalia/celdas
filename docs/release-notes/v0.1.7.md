Celdas 0.1.7 arregla el actualizador integrado: las descargas ya no fallan con un error 403 ni se quedan a medias.
*Celdas 0.1.7 fixes the built-in updater: downloads no longer fail with a 403 error or stop halfway.*

## Español

### Novedades
- Los 18 idiomas de la interfaz traducen ya todos los textos (menús, cinta, diálogos, Solver, impresión, tablas dinámicas, protección y preferencias); antes muchos aparecían en inglés.

### Correcciones
- **Actualizador:** buscar e instalar una versión nueva ya no falla con «http status: 403».
- **Descargas que se cortan:** si la conexión se queda parada, la descarga se reanuda donde iba en lugar de empezar de cero o fallar con «timeout: receive body».
- Los errores del actualizador se explican en español.

## English

### What's new
- All 18 interface languages now translate every string (menus, ribbon, dialogs, Solver, printing, PivotTables, protection and preferences); many used to appear in English.

### Fixes
- **Updater:** checking for and installing a new version no longer fails with "http status: 403".
- **Interrupted downloads:** when the connection stalls, the download resumes where it left off instead of starting over or failing with "timeout: receive body".
- Updater errors are explained in plain language.
