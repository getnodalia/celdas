Celdas 0.1.4 protege las macros VBA al guardar libros en formatos que no las admiten.

*Celdas 0.1.4 protects VBA macros when saving workbooks to formats that do not support them.*

## Español

### Correcciones

- Al guardar un libro con VBA como `.xlsx` o `.xltx`, Celdas rechaza la operación para evitar que las macros se pierdan silenciosamente. La API permite autorizar expresamente su descarte.
- Los archivos `.xlsm` y `.xltm` conservan el proyecto VBA al guardarse. La ejecución y edición de macros VBA todavía no están implementadas.

## English

### Fixes

- When saving a workbook containing VBA as `.xlsx` or `.xltx`, Celdas rejects the operation to avoid silently discarding macros. The API can explicitly authorize their removal.
- Saving `.xlsm` and `.xltm` files preserves the VBA project. Running and editing VBA macros are not yet implemented.
