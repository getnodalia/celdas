Celdas 0.1.5 añade GETPIVOTDATA, Subtotal y WordArt, rediseña Orden personalizado y exporta a PDF texto en árabe y de derecha a izquierda.

*Celdas 0.1.5 adds GETPIVOTDATA, Subtotal and WordArt, redesigns Custom Sort and exports Arabic and right-to-left text to PDF.*

## Español

### Novedades

- Función `GETPIVOTDATA` para leer valores de una tabla dinámica.
- Comando Subtotal para agrupar y totalizar filas.
- WordArt para insertar texto decorativo en la hoja.
- El cuadro Orden personalizado tiene un diseño nuevo, y las ordenaciones por listas personalizadas funcionan como se espera.
- La exportación a PDF dibuja el texto en árabe y de derecha a izquierda.
- El Administrador de reglas de formato condicional se desplaza dentro del cuadro con miles de reglas, en vertical y en horizontal.

### Correcciones

- XLSX: se conserva una fila de totales oculta, el primer número de página de Configurar página y se avisa de cachés de tablas dinámicas que no se pueden leer.
- Arreglos en la barra de título en Linux y mejoras de rendimiento.

## English

### What's new

- `GETPIVOTDATA` reads values from a pivot table.
- The Subtotal command groups and totals rows.
- WordArt inserts decorative text on the sheet.
- The Custom Sort dialog has a new design, and sorting by custom lists works as expected.
- PDF export draws Arabic and right-to-left text.
- The Conditional Formatting Rules Manager scrolls inside the dialog with thousands of rules, both down and sideways.

### Fixes

- XLSX: a hidden Total Row and Page Setup's first page number are kept, and pivot caches that cannot be read show a warning.
- Linux title bar fixes and performance work.
